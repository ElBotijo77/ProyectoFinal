# MedicApp · Android

Aquí irá la app móvil (Kotlin + Jetpack Compose).

**Todavía no existe.** Se creará más adelante desde Android Studio con el asistente
*New Project* (plantilla *Empty Activity*), eligiendo esta carpeta `android/` como
ubicación del proyecto.

Esta carpeta se abre **siempre en Android Studio**, nunca desde VS Code ni abriendo
la raíz del monorepo.
